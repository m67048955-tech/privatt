# Baraka Market

Faqat HTML va CSS bilan yozilgan supermarket template.

## Ochish
index.html faylini brauzerda oching yoki VS Code Live Server orqali ishga tushiring. O‘rnatiladigan kutubxona yo‘q, internet talab qilinmaydi.

## Fayllar
- index.html — sahifa va mahsulot kartalari.
- style.css — ranglar, responsive dizayn, CSS filtrlar va modal.
- images/ — banner, kategoriya, mahsulot, aksiya va yetkazib berish suratlari (JPG).

## Rasmlar
Suratlar [Unsplash](https://unsplash.com/license) litsenziyasi asosida olingan: bepul, tijoriy maqsadda ham ishlatish mumkin, muallifni ko‘rsatish shart emas. Haqiqiy mahsulot suratlari tayyor bo‘lganda images/ ichidagi fayllarni xuddi shu nom bilan almashtirish kifoya.

Mualliflar: Archer Fu (hero), Aleksander Joachimiak (pomidor), Thought Catalog (avokado), an_vision (sut), Gabriel Mihalcea (banan), Monika Grabkowska (baton), IamCristian (olma), David Foodphototasty (pishloq, kategoriya-pishloq), Greg Rosenke (apelsin-sharbati), Julia Zolotova (kategoriya-meva), Ahmadreza Rezaie (kategoriya-sut), personalgraphic.com (kategoriya-non), Sandie Peters (kategoriya-ichimlik), Lucas Oliveira (kategoriya-tamaddi), Nathan Dumlao (aksiya-vitamin), Alina Chernysheva (aksiya-pishiriq), Ginny Rose Stewart (yetkazib-berish).

## Tayyor qismlar
Mobil/desktop dizayn, kategoriya filtrlari, sevimli belgisi, FAQ va savat haqida modal. Filtrlar CSS orqali ishlaydi. Sevimli belgilari doimiy saqlanmaydi.

## Keyingi bosqich
Mahsulotlar, narxlar, chegirmalar va brend matnlari namuna. Backend, JavaScript, haqiqiy savat, qidiruv, akkaunt, to‘lov yoki buyurtma saqlash yozilmagan. Headerdagi katalog havolasi mahsulotlarga olib boradi. Plus tugmasi template haqida oynani ochadi.

Backend ulashda .products ichidagi article.product elementlarini server shabloni sikliga ko‘chirish, narx va kategoriyalarni bazadan chiqarish, .add havolalarini savat amallariga almashtirish mumkin.
